Maqbool

Your files, on your Mac

The optional Mac companion connects Maqbool to a folder you choose. Use it to publish reviewed files or edit supported office documents inside Maqbool.

Download for Apple silicon Mac

Your workspace works without it. You can still upload, preview, review and download files.

Set up once

  1. Unzip the download and keep the whole Maqbool Companion folder in Applications or another convenient location.
  2. Open Setup.command. Enter this Maqbool website’s address and choose the shared folder you want to use.
  3. Choose Shared folder only, or enable optional editing. Editing needs Docker Desktop already running and at least 4 GB of available memory. The first download can take several minutes.
  4. Approve the Mac’s certificate confirmation for localhost. This lets your browser securely connect to this computer.
  5. Open Start.command and keep its window open. Your connection code appears in the browser.
  6. As a workspace Owner, open your project’s Delivery → More → Shared folders. Enter the code and confirm the folder. If your browser asks for local network access, allow it.
If macOS asks for Apple Command Line Tools, install them and run Setup again. This initial package is not notarized; use macOS’s normal Open confirmation after checking the download came from your Maqbool website. Do not disable your Mac’s security settings.

Working with documents

Inside Maqbool, Save new version keeps the original and saves your edits separately. When editing on your computer, upload the updated file afterwards. Changes do not sync automatically.

Each computer needs its own companion for local editing. Other people can continue to use uploads and downloads. The shared folder must be accessible on the computer publishing the delivery.

If something stops

After a workspace restore or an Owner removes access, close Start.command and open New connection.command. Confirm the replacement, reopen Start, and have an Owner connect its new code. Your chosen folder and earlier publication records are kept.

Open Start.command and check your local connection. For editing, also check Docker Desktop is running. If a file has changed or the disk is full, review the issue and resume from Maqbool. Unexpected files are never silently replaced.

Keep the hidden .maqbool-delivery folder inside your shared folder until publication and recovery are complete. It holds local publication records and previous files. The cloud does not back up files kept only on your drive.

Downloading a delivery package is separate from publishing it. Maqbool records publication only after the companion verifies the final files.

Close the companion window to stop it. Revoke the folder connection in Maqbool when it is no longer needed. The download includes fuller troubleshooting, privacy information and open-source notices.
