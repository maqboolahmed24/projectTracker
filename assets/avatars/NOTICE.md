Changes: 20 fixed combinations were curated from the upstream component artwork; primary and accent fills were replaced with `currentColor`; ink was set to `#243247`; background and animation were omitted; a transparent 120 × 120 frame adds consistent space; unused classes were removed and local clipping identifiers were prefixed by shape ID. No original source imagery from Bottts or any other researched style is included in this collection.

The pinned source JSON retains its original licence and creator metadata. The DiceBear rendering library is not bundled, installed or used at runtime. The application serves these fixed local templates and its fixed palette; it does not contact DiceBear or send user data to an avatar service.
