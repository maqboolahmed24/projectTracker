Studio North — Team Welcome Guide

Operational Guidelines · Internal Release v2.0

1. Purpose & Scope

This document serves as the primary onboarding walkthrough for cross-functional contributors joining Studio North projects. All members should review these working principles during their initial intake week.

2. Core Workflows

All sprint work is organized into structured milestones and documented handoffs. Tasks require verified attachments before passing into the independent review phase.

  • Keep source document references attached to corresponding tasks.
  • Verify output formats prior to submitting a batch for review.
  • Ensure reviewer approval before closing deliverable items.

3. Document Conventions

Working files should use standardized naming with project prefixes (e.g., HR-001) to support reliable tracking across deliverables and sprint timelines.
